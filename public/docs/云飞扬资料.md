## 二、成立背景与宗旨

云飞扬社团成立于 **2014 年**，由学校**第一届云计算专业学生**在老师指导下创建。

### 成立初衷

* 紧跟计算机行业发展趋势
* 构建高质量技术学习与实践平台
* 培养学生工程实践能力与创新能力

### 核心宗旨

* 坚持 **以成员为中心**
* 突出 **技术学习的核心地位**
* 注重 **自主学习、实践能力与职业规划**
* 帮助成员将 **兴趣爱好与计算机行业发展相结合**

## 三、研究与学习方向

### 专业技术方向

1. **人工智能**
   * **定位**：探索大模型、计算机视觉与智能体前沿，运用 AI 原理与算法解决实际工程问题。
   * **核心技术**：Python 编程、机器学习、深度学习、大模型应用、智能体开发、计算机视觉、智能机器人。
2. **软工智能**
   * **定位**：融合软件工程思想与 AI 智能体工具，打造智能化企业级软件系统。
   * **核心技术**：软件工程、智能体开发、大模型应用开发、Web 全栈开发、系统架构设计。
3. **数据库**
   * **定位**：面向信创与国产替代需求，深耕分布式数据库架构、性能调优与数据治理。
   * **核心技术**：数据库原理、国产分布式数据库 (openGauss / OceanBase)、NoSQL 数据库、数据挖掘与治理。
4. **智能云物联**
   * **定位**：聚焦端-边-云一体化，融合物联网嵌入式开发、云计算与智能硬件应用。
   * **核心技术**：云物联技术、云计算与边缘计算、嵌入式开发、物联网通信协议、云平台开发。
5. **工业数智化**
   * **定位**：软硬件结合赋能工业 4.0，深耕工业软件架构、智能控制与设备状态监测。
   * **核心技术**：工业软件开发、PLC 控制、嵌入式系统、物联网感知与通信、工业智能技术。

> 官网参考：[计算机与软件学院简介 - 南阳理工学院招生信息网](https://zsw.nyist.edu.cn/info/1230/9416.htm)

### 编程与技术栈

* C / C++
* Java / Go / Rust
* Python
* MySQL / openGauss / Redis / NoSQL
* Web 全栈开发 (Vue / React / Node.js / JavaWeb)
* 云原生与容器化 (Docker / K8s)
* 嵌入式与物联网开发
* 大模型与智能体开发
